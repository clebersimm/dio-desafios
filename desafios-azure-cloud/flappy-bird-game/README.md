# Flappy Bird Game

This is a simple implementation of the classic Flappy Bird game using HTML, CSS, and JavaScript. The game features a bird that the player must navigate through a series of pipes by clicking or tapping on the screen.

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/flappy-bird-game.git
   ```
2. Navigate to the project directory:
   ```
   cd flappy-bird-game
   ```
3. Open `src/index.html` in your web browser to start playing.

## How to Play

- Click or tap on the screen to make the bird flap.
- Avoid the pipes to keep the game going.
- Try to score as many points as possible by passing through the pipes.

## Game Features

- Simple and intuitive controls.
- Responsive design that works on various screen sizes.
- Fun and engaging gameplay.

- `bird.png`: The image of the bird character.
